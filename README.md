# BeaverTalk

외국인 학습자를 위한 AI 기반 한국어 회화 학습 애플리케이션입니다.

사용자는 AI 캐릭터와 자연스럽게 대화하며 한국어 회화와 발음을 학습할 수 있습니다.

## 📦 프로젝트 실행 방법

### 1. 저장소 클론

```bash
git clone https://github.com/your-org/beavertalk.git
cd beavertalk
```

### 2. 패키지 설치

```bash
flutter pub get
```

### 3. 애플리케이션 실행

```bash
flutter run
```
